Challenge 1: Coin Value Calculator

Write pseudocode that asks the user for the number of quarters, dimes, and nickels. Calculate the total value in pennies (cents) and display the total result.

Assume the following values: Quarter = 25 pennies, Dime = 10 pennies, Nickel = 5 pennies.

Rule Checklist / Quick Guide

  • Start : Begins the algorithm. Must be the very first keyword.
  • Input : Reads data from the user (e.g., quarters, dimes, nickels).
  • Set : Assigns or calculates a value (e.g., total = quarters * 25 + dimes * 10 + nickels * 5).
  • Output : Displays the calculated result to the user.
  • End : Finishes the algorithm. Must be the final statement.
